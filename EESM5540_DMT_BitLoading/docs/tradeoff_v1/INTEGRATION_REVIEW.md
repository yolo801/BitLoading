# tradeoff_v1 集成审阅记录（非MATLAB运行报告）

用户最新范围为交付可下载代码包，由用户运行MATLAB。本次完成新增入口、物理前端、设计/统计/恢复/验收与绘图的源级实现和交叉接口审阅。旧MATLAB函数不修改；基于实际存在的v1.3组帧、Gray解调、随机流、数学与哈希原语接入，不虚构缺失v15参考接口。

## 核对重点与最终行为

- 前端物理顺序为含CP的p=clip(b*(1+x/(rho*sigma_ref)),0,2)，因果h*p加固定热噪声，再固定范围mid-rise ADC，去CP/FFT；ADC前不去DC、不加AGC，p不作为场幅平方。
- 每份TX校准只生成一次8192符号波形，保存波形SHA-256和全部二分观测；不读取接收端或payload数据。M每次变化都有独立功率校准与当前M下新A_r及完整D_r。
- 共享A0/B0值对象以内容hash绑定到两个独立策略；初始gamma还与实际共享记录逐项相等。设计只使用B0质量和D验证，不接收正式计数。
- Uniform整表退阶、Loaded只退未支持载波，所有候选都完整重测；最低阶拒绝/四轮耗尽/无初选均终止设计而不伪造接受表。最终M/b/q/ADC范围/H身份/功率和D来源绑定双方配置副本与ACK。
- 载荷Tx和Rx分别使用本地M表，冻结b/H/ADC；一个完整正式组为50000符号、3600000含CP样本。power_mismatch保留真实计数，科学失败不停止其他组。
- 计划与预期行数从配置列表及重复数派生。全可接受时300组、7200逐seed载波行、3600pooled载波行、150设计case；拒绝时有效计数行减少且300槽状态保留。不能把配置预算当完成证据。
- 恢复先只读核对协议/source/config/plan，再创建锁/写日志，误指旧目录不改旧日志。MATLAB/Communications版本及平台变化要求新目录。中断未完成单元仅按原种子重放，完整计数不叠加；损坏或身份不符的完整检查点不静默复用。
- 实际MATLAB `which -all`、版本、工具箱路径、源码快照与角色种子计划在用户运行时记录。机械预检和保存记录的独立语义复核通过后才冻结Protocol；全部科学拒绝不作为性能门槛，会先做固定机械回放及保存记录诊断，参数/种子不变后继续正式矩阵。
- Protocol MAT与JSON完整规范化核对，绑定真实预检及机械报告；正式结束日志先刷盘再独立核对。验收分开原始数据完整性、导出/协议完整性、计划完成量与科学表现，部分有效记录可只读重绘。
- CSV核对保留整数计数的精确性，并处理空字符串、缺失列和浮点速率舍入；源快照按原字节SHA-256验证。图清单绑定实际表的hash，导出失败不会被标作最终完成。
- R_cycle按单个L周期扣A0/B0及全部实际A_r/D_r，TX离线校准不加链路时长；总BER按总错误/总bit，两个payload仅作统计重复。场景实心点要求五轮全部正式支持且所有重复功率匹配，业务门槛用五轮最小R_cycle，经验预算用所有重复最大实测功率，不插值或声称容量边界。
