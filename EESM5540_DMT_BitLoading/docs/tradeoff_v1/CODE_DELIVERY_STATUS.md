## 必须保留的科学边界

- `b`和`P_actual`分开；payload功率超1%保留原计数并标记，不调整波形配平。
- Dr接受不代表正式BER已支持；正式状态与完整性/完成量分开。
- 同cal/condition/scheme的两个payload重复才可合并；不能跨不同M表合并证明逐轮合规。
- 业务门槛采用R_cycle，包含初始A0/B0及所有实际Ar/Dr轮次，不把重复种子拼成2L周期。
- 只有五轮都满足BER且正式功率匹配，场景点才可表示受支持结果；失败/拒绝/不确定/未完成都保留。
- 归一化采样点IM/DD+热噪声+理想ADC不是完整真实光链路，功率/量化能力/软件时间不等于mW、ENOB、价格或整机功耗。
