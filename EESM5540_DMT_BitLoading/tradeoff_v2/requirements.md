# Codex 提示词：DMT tradeoff_v2 — 三种调制策略、ADC 位数与平均光功率

请在 `BitLoading/EESM5540_DMT_BitLoading` 的独立工作树或独立 v2 工程实现本实验。先核对本机实际源码、`which` 解析路径和现有 v1 快照。保留 v1 的源码清单、协议、检查点、正式数据和失败回执原字节；v2 使用独立入口、结果目录、源码清单及随机种子计划。不要修改历史 v1 文件，也不要把它的 `UniformAdaptive` 结果改名为新 `Fixed QPSK`。旧 `Fixed16` 不进入 v2 主矩阵；本轮不加 16-PSK、16-QAM 固定基线、FEC、AGC 或功率加载。

## 1. 研究问题和可检验假设

在同一简化 IM/DD 模型、同一实测平均光功率约束和逐载波未编码误码要求下，比较 **Fixed QPSK、Fixed 64-QAM、Validated Bit Loading** 的可用工作点与周期速率。扫接收 ADC 位数是为了量化较粗量化是否使高阶星座或弱载波更难达标，以及自适应加载能否在较少量化级数下保留周期速率收益。不得预设 8 位一定更优、固定 64-QAM 一定失败、或加载一定获益。

区分两类问题：固定调制表下跨 ADC 的比较反映这一接收机模型中的量化影响（包括量化后的信道估计变化）；允许调制表随 ADC 改变的比较反映端到端策略表现。将削波与量化的受控归因放到第 6 节的独立诊断。理想 ADC 位数只是模型参数，不是实测 ENOB、整机耗能或器件价格。

## 2. 主扫描冻结规格

- 延用 v1 的模型：实值 Hermitian 对称 DMT，`NFFT=64`、`NCP=8`、`Fs=64e6`、24 个独立正频率有效子载波 `k=1:24`，每个数据子载波平均星座符号能量 `Es=1`，`Ts=(64+8)/Fs=1.125 us`。固定 FIR `h=[0.25,0.5,0.25]`、热噪声方差 `1.0491e-4`、发射峰值 `P_peak=2`、`rho=4`；保留现有归一化、已知训练和均衡接线。不要因为显示图而改变科研参数。
- **目标归一化平均光功率** `[0.6,0.8,1.0,1.2,1.4]`；**接收 ADC 位数** `[4,6,8]`。实值波形经过信道和噪声后，在去 CP 和 FFT 前，使用固定输入范围 `[-0.1,2.1]` 的饱和型均匀 mid-rise ADC；不加 AGC。核对电平数 `2^q`，步长 `2.2/2^q`，并单独记录超出输入范围的样本数。端点本身不计越界。
- 每个 `(P_target,q)` 五次校准；每策略每次校准对应两个独立载荷槽，每槽 `50,000` DMT 符号。总计划 `5×3×5×3×2=450` 槽，其中固定两组 300 槽、比特加载 150 槽。未发、未测、拒绝和有效发送均保留状态。五轮是同一固定信道下的不同随机实现，不是五个实测物理信道。
- 生成机器可读 seed plan，签入方案身份。新命名空间与 v1 已知流分开；`preflight`、`formal`、`impairment_diagnostic` 不交叉。跨校准、两个载荷重复、TX 功率校准、训练、探测、设计验证与载荷的流必须彼此独立。对同一 `(P_target,calibration_id,payload_slot)` 的不同 ADC 位数与策略，预先指定公共噪声流；固定调制在不同 ADC 位数下复用同一数据波形和相同的 TX 校准。若跨调制配对数据，按固定形状、均匀的载波/符号随机源映射，验证不会因某组比特数、分块或读取顺序不同而破坏载波和时间对齐。计划表明确列出允许的配对复用，检查其余碰撞。禁止载荷观测参与设计和复调参。

## 3. 三组策略、功率与开销

1. **Fixed QPSK**：24 个载波全部 QPSK，48 bits/DMT symbol，名义 42.6667 Mbit/s。
2. **Fixed 64-QAM**：24 个载波全部 64-QAM，144 bits/DMT symbol，名义 128.0000 Mbit/s。
3. **Validated Bit Loading**：24 个载波保持有效，沿用 v1 的 QPSK 共享探测、1 dB 设计余量、`{QPSK,16-QAM,64-QAM}` 逐载波初选，以及独立验证、必要降阶与最终冻结流程；最多四轮，保留拒绝原因。验证样本不能算入载荷统计。

- 三组按所用调制表分别执行现有独立 TX 功率校准：用固定的 8192 符号校准波形求偏置/驱动系数，削波后、含 CP 的平均光功率相对目标误差不超过 0.2%。每组冻结后，两个载荷的实测功率各自相对目标偏差必须不超过 1%。作同点配对增益时，同一校准、同一载荷号的两策略实测平均光功率差还须不超过该目标的 1%；不满足则保留记录并注明不可直接配比。正式图横轴区分 target 与 measured，功率为归一化量，不能写成 dBm。
- 固定组分别使用自身已冻结调制及功率下的 **1024 个已知 DMT 训练符号**估计信道。检查配置、功率校准及接收端同步身份后正常发载荷；不要通过加载初选或 `D_r` 接受门禁。即使预计 BER 很高也完整发送，不能降阶、关闭弱载波、用理论 BER 填结果或因早期误码停计。按项目现有结构新增明确的固定组授权分支；不得伪造已通过 `D_r` 或改写加载验证。无法实现功率或工程异常单列。
- 加载组按实际发生记录 `A0=1024`、`B0=2048`、每轮 `A_r=1024`、`D_r=8192` 及反馈/配置记录。固定组不用的加载探测只可用于诊断图，不计入它的在线时间。TX-only 功率求解及独立结果复核不计为链路传输时间，另报软件耗时。
- 同时报 `R_nominal = sum(b_k)/Ts`、在线训练/探测/验证符号数及 `R_cycle = L·sum(b_k)/[(L+N_setup)·Ts+T_control]`，其中 `L=50000` 是单次周期载荷，两个统计重复不能合成 `2L`。继续沿用 `T_control=0` 的理想反馈时延假设，列出反馈项目/数量，不虚构序列化位数。`R_cycle` 是模型中的周期载荷速率，不能称为实测应用层 goodput；不达标配置的名义值不是合格速率。

## 4. 判据、输出和复核

每次校准按 `(strategy,P_target,q,k)` 合并两个独立载荷的整数错误位数与测试位数，再算 `BER=e/n` 及 `z=1.96` 的逐载波近似 95% Wilson 区间。仅在两槽都完整、功率匹配且 **所有 `U_k < 1e-3`** 时标 `supported`。任一载波下限 `>1e-3` 标 `ber_failed`；未触发失败但上限达不到严格判据标 `inconclusive`。`design_rejected`、`power_mismatch`、`incomplete` 分开保存。上限等于门限不能算通过；零错仍保存正的上限。不可把逐点区间描述成 24 个载波同时的 95% 保证。五轮均通过的点才进入 `qualified`；五轮 min–max 是观测极值，不是置信区间。

保存独立原生 MAT 检查点和 CSV：带版本/阶段/种子/校准/重复身份的计划与状态、逐载波整数误码及 Wilson 区间、实际功率及匹配状态、削波与 ADC 越界、加载表、共享探测 SNR、各阶段开销、每轮 `Umax=max_k(U_k)`、每轮及五轮的速率，以及图件与源表的哈希绑定。保留未接受条件，不用 `0` 或 NaN 替代有效计数。搭建只读核验，复算整数池化、Wilson、逐轮状态和速率，并区分“运行完成”“科学条件未达标”“验收失败”。检查 `unique` 等内置函数名未被局部变量遮蔽；验证器的失败不应修改已冻结统计或清除旧回执。

## 6. 单独实施的 2×2 诊断（不算进 450 槽）

主实验独立验收后才另行准备。固定高功率 `P_target=1.4`，固定诊断加载表（`k=1:15` 用 64-QAM，`k=16:20` 用 16-QAM，`k=21:24` 用 QPSK），用不同于正式矩阵的随机流，采用五次配对校准，每组两份独立载荷。发射上限 `2` 与 `3`，交叉接收 6-bit 量化与连续幅度参考，共 40 个诊断载荷槽。外生信道、比特、噪声、FFT/CP、估计方法一致，每个处理组可重新估计信道，不能用载荷重估。两上限支路都保留非负下限：诊断发射写成 `p=clip(d+g*x,0,P_peak)`，配对内固定相同的交流驱动增益 `g`（由原上限 2 的独立 TX 校准得到），按独立校准序列分别只求 `d` 以匹配削波后光功率。冻结后核对两边实际光功率，不达容差单列。不要通过直接复用原先同时改变 DC 和 AC 的 `b` 来宣称单独隔离削波。

接收端两支路保留相同的 `[-0.1,2.1]` 饱和范围：连续参考显式执行 `min(max(y,lo),hi)`，仅省去幅度取整。有些已有 `adcBypass` 实现直接返回原始 `y`，同时去掉输入饱和，不能直接拿来做此对照。保留原量化器路径，另在诊断实现共同饱和的参考。报告削波、接收越界和量化应分别观察；固定表诊断不产生新的正式选阶结果。
